# QR Studio Bot

Telegram-бот `@QUaRc0De_bot`: превращает ссылку или текст в стилизованный QR-код.

Демо: https://qr-studio-bot.onrender.com/healthz

## Возможности

- 52 силуэта: геометрия, природа, животные, символы.
- 24 стиля модулей и 14 стилей «глаз» (угловых маркеров).
- 19 палитр, включая градиенты, металл, дерево и акварель.
- 25 готовых пресетов и случайный стиль.
- Логотип: плашка, медальон, вырез, текстура, фон, угол, монограмма.
- 12 встроенных нейтральных иконок для центра QR; свой логотип тоже можно загрузить.
- Фото-режим: пришли фотографию — QR ляжет на светлую карточку в углу, фото останется видимым.
- QR вписывается в силуэт: без квадратной плашки, с лёгким тинтом и рантом; для сложных форм используется безопасная рамка.
- PNG до 2048 px с DPI 300 и SVG для печати.
- Проверка контраста и безопасные fallback-стили, чтобы QR оставался читаемым.
- Русский и английский интерфейс: выбор языка при первом `/start`, команда `/language`, подсказки и предупреждения о рисках сканирования.
- Визуальный редактор в Telegram Mini App: превью и плитки вариантов вместо текстовых списков; язык интерфейса синхронизируется с ботом.

## Стек

- Python 3.13+ (проверено на 3.14)
- aiogram 3.32
- segno 1.6.6
- Pillow 13
- aiohttp
- asyncpg 0.32 + PostgreSQL (Supabase) для аналитики

## Локальный запуск

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env
# впиши BOT_TOKEN
BOT_MODE=polling python -m bot.main
```

Для polling токен можно получить у [@BotFather](https://t.me/BotFather).

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `BOT_TOKEN` | — | Токен Telegram-бота, обязателен |
| `BOT_MODE` | `webhook` | `webhook` или `polling` |
| `WEBHOOK_BASE_URL` | `RENDER_EXTERNAL_URL` | Публичный HTTPS-адрес сервиса |
| `WEBHOOK_SECRET` | hash токена | Hex-секрет заголовка `X-Telegram-Bot-Api-Secret-Token`; можно не задавать |
| `SELF_PING_INTERVAL_SECONDS` | `600` | Пинг `/healthz`, чтобы free-сервис не засыпал |
| `ADMIN_ID` | — | Telegram ID администратора для `/stats` |
| `DATABASE_URL` | — | PostgreSQL URL для аналитики; без него бот работает как раньше |
| `MAX_CONTENT_LENGTH` | `1200` | Максимум символов в QR |
| `MAX_LOGO_BYTES` | `6291456` | Максимум размера логотипа |

Секреты не коммитятся: `.env` и `.secrets/` уже в `.gitignore`.

## Деплой на Render

В репозитории есть `render.yaml` (free web service, Frankfurt, health check `/healthz`).

1. Создай Blueprint или Web Service из репозитория.
2. Укажи `BOT_TOKEN`; `WEBHOOK_SECRET` можно не задавать — он будет вычислен из токена. Если задаёшь вручную, используй только hex (без спецсимволов), иначе Telegram отклонит webhook.
3. `WEBHOOK_BASE_URL` подхватится из `RENDER_EXTERNAL_URL`.
4. Для аналитики добавь `DATABASE_URL` от Supabase/Postgres и задай `ADMIN_ID`.
5. После деплоя открой `https://<service>.onrender.com/healthz` и `/app`.

Free-план засыпает без трафика. Бот пингует себя раз в 10 минут; первый запуск после сна занимает около минуты.

## Визуальный редактор (Mini App)

Mini App открывается кнопкой меню «QR Studio» рядом с полем ввода, командой `/app` или кнопкой «Выбрать визуально» в редакторе. Превью и плитки формируются на том же aiohttp-сервере. Выбор отправляется в бота через `POST /app/apply` с подписанным `initData`; сервер проверяет HMAC и передаёт настройки в обычный handler `web_app_data`. Для keyboard-кнопок сохранён fallback через `WebApp.sendData`. Если настройки выбраны до создания QR, бот сохранит их и применит к следующему тексту.

Язык Mini App выбирается в порядке URL `?lang=`, сохранённого выбора в `localStorage`, `initDataUnsafe.user.language_code` и `navigator.language`; `/app/catalog.json?lang=en` отдаёт английские названия. В шапке Mini App есть переключатель RU/EN: он сразу перерисовывает интерфейс и каталог, а `Apply` отправляет `lang` в бота. После `/start`, `/language` или Apply бот обновляет per-chat menu button с `?lang=`, поэтому следующий запуск из меню открывает редактор на выбранном языке. Глобальная кнопка без `lang` остаётся fallback.

Статические плитки лежат в `webapp/thumbs/`. После изменения форм или стилей пересобери их:

```bash
python scripts/build_miniapp_thumbs.py
```

Mini App работает в webhook-режиме; в polling-режиме кнопка ведёт на публичный Render-адрес. Статика и шаблоны находятся в `webapp/`.

Фото-режим доступен в боте: кнопка «Фото + QR» на стартовом экране или «Фото» в редакторе. Загруженное фото не участвует в статическом каталоге Mini App.

## Аналитика

При наличии `DATABASE_URL` бот создаёт схему `analytics` и пишет туда пользователей и события. Это не мешает работе бота: если база недоступна, обновления продолжают обрабатываться, а ошибки только логируются.

- `analytics.users` — `user_id`, `username`, `first_name`, `language_code`, `first_seen`, `last_seen`, `updates_count`, `starts_count`, `last_event`, `blocked_at`.
- `analytics.events` — `user_id`, `event_type`, `created_at`, `metadata`; текст сообщений и содержимое QR не сохраняются.
- События: `/start`, команды, сообщения, Apply Mini App, скачивания PNG/SVG, смена языка/формы/узора/палитры, пресеты и фото.
- `/stats` показывает всего пользователей, новых за сегодня/7/30 дней, активных за 15 минут/день/7/30 дней, неактивных 30+ дней, заблокировавших бота и топ событий. Команда доступна только при заданном `ADMIN_ID`.

Точного события «пользователь ушёл» Telegram не присылает: в private-чате нельзя узнать, закрыл ли человек чат или удалил бота. Поэтому «ушёл» — это отсутствие активности 30+ дней; статус `blocked_at` выставляется только когда Telegram сообщает `403`, например при рассылке.

## Проверки

```bash
ruff check qrstudio bot scripts tests
pytest -q
python scripts/check_scans.py
```

`scripts/check_scans.py` рендерит 262 QR-кода (включая все 52 формы в режиме силуэта, 25 пресетов, 12 встроенных иконок и фото-сценарии) и декодирует их через jsQR (`tests/js/decode.js`). Нужен Node.js и `npm install` в `tests/js/`.

## Структура

```

```

## Ограничения

- Максимум 1200 символов и 2048 px.
- Логотип до 6 МБ (жёсткий лимит загрузки — 8 МБ).
- Фото до 12 МБ; для рендера уменьшается до 1600 px по длинной стороне.
- В фото-режиме форма и silhouette не используются: QR размещается на карточке поверх фото.
- Встроенные иконки нейтральные, без брендовых логотипов; для бренда загрузи свой файл.
- В SVG силуэты и логотип встраиваются как PNG, а модули QR остаются векторными. Это сохраняет точное совпадение с PNG.
- Mini App требует HTTPS. В локальном polling-режиме кнопка использует публичный адрес сервиса, а не localhost.
- При мелких модулях бот автоматически упрощает слишком детальный узор и предупреждает об этом.
- Выбор языка хранится в FSM (`MemoryStorage`) и может сброситься после рестарта Render; при следующем `/start` бот снова предложит выбрать язык, а direct messages используют язык Telegram.
- Per-chat menu button обновляется после `/start`, `/language` и Apply; если обновление API не удалось, остаётся глобальная кнопка без `lang`. `localStorage` хранит выбор Mini App на устройстве.
