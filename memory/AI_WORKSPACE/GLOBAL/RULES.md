# Rules

1. Секреты, токены и ключи не попадают в репозиторий и память.
2. Перед изменениями читаем актуальные файлы проекта.
3. Каждый этап заканчивается проверкой: ruff, pytest, scan-регрессия.
4. Успешная сборка не считается доказательством работоспособности.
5. Решения и ошибки фиксируются в памяти проекта.
6. Не используем чужие Render-воркспейсы и ключи.
